# Benji Bakery Website

Student: Chelsea Harris (20241097) | Course: INFO 0211 - Web Design

## Structure
- `index.html` - Home page
- `about.html` - About Us page (history, mission/vision, team)
- `menu.html` - Products/Services page (Daily Menu)
- `order.html` - Functional input form page (Custom Cake Order, with JS + HTML5 validation)
- `contact.html` - Contact Us / Locations page
- `css/style.css` - External stylesheet (colours, type, layout, responsiveness)
- `js/main.js` - Mobile navigation toggle (shared across all pages)
- `js/validation.js` - Custom JavaScript validation for the order form

## Before You Submit
1. Deploy this folder to Netlify (drag-and-drop) or GitHub Pages.
2. Run the live site through the W3C Markup Validator (validator.w3.org) and
   the WAVE accessibility tool, and screenshot the results for your report.
3. Test the live site in Chrome, Firefox, and Edge; screenshot each.
4. Test the live site at desktop, tablet, and mobile widths; screenshot each.
5. Test the order form: one submission with empty fields, one with an
   invalid email/phone, and one fully valid submission; screenshot each.
